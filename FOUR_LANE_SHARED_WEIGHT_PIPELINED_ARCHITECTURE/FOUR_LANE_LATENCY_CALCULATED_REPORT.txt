FOUR-LANE PIPELINED SHARED-WEIGHT ARCHITECTURE
-----------------------------------------------
Number of lane groups:
  G = ceil(N / 4)

The calculated four-lane latency includes:
  - One Pre-DyT phase per lane group
  - One FFN phase per lane group
  - One Post-DyT phase per lane group
  - 1024 output reorder/serialization cycles per vector
  - One restart cycle between lane groups

  L_four_lane = G x (L_pre + L_ffn + L_post)
