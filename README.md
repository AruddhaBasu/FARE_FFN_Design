In this repository, systematic design of the pipelined feed forward network has been discussed. At first, a feed forward network with smaller parameters is designed and then tested using a testbench. Then the parameters are set to higher values, again tested with a test bench, synthesis is done and the reports are provided. Based on the resource utilization report, another version of feed forward network has been implemented that takes significantly less number of dsp, lut and IOBs. This second design is also tested with the same testbench.
